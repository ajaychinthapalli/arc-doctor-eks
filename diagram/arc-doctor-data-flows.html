ARC Doctor: EKS runner diagnostics

Flows 1–4 are ARC starting a runner. Flows 5–14 are ARC Doctor spotting a stuck runner and explaining why. Every diagnosis read is read-only, and only two calls leave the cluster: Bedrock and Slack.

What never moves

No Kubernetes Secrets are read: the GitHub credentials stay with the listener, and the agent infers bad credentials from listener logs.

No write reaches the cluster from the diagnosis path. The only object ARC Doctor writes is its own cooldown ConfigMap (flow 6).

Nothing enters the cluster from outside: GitHub, Bedrock and Slack are all reached by connections the cluster opens.
